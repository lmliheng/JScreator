# 博客前端设计规范（hugo-theme-stack 迁移版）

本规范要求博客前端**完全模仿 [hugo-theme-stack](https://github.com/CaiJimmy/hugo-theme-stack)**（卡片式 Hugo 博客主题），迁移到 Vue3 + Tailwind 4。配色/圆角/间距直接取自该主题的 `variables.scss`。

## 核心气质

卡片式、侧边栏布局、简洁克制、支持暗色/亮色切换。内容以卡片呈现，页面浅灰背景 + 白色卡片，圆角柔和。

## 圆角 & 间距

- 卡片圆角：`10px`
- 标签圆角：`4px`
- 卡片内边距：`20px`（md 屏 `25px`，xl 屏 `30px`）
- 区块间距：`40px`
- 页面顶部留白：`35px`（xl 屏 `50px`）

## 字体

- 正文字体：`Lato` + 系统字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", "Droid Sans", "Helvetica Neue", sans-serif`）
- 代码字体：`Menlo, Monaco, Consolas, "Courier New", monospace`
- 文章正文字号：`1.6rem`（md 屏 `1.7rem`），行高 `1.85`

## 布局

1. **左侧固定侧边栏（Sidebar）**：头像（圆形）、昵称、简介、导航菜单、社交图标。桌面端固定在左，移动端收起为顶部折叠菜单。
2. **主内容区**：位于侧边栏右侧，卡片式文章列表。
3. **文章卡片**：封面图（可选）+ 标题 + 分类标签 + 摘要 + 日期/阅读时长。卡片网格布局（大屏多列，小屏单列）。
4. **文章详情页**：封面图 + 标题 + 元信息（作者/日期/分类/标签）+ 正文（Markdown）+ 目录（TOC）+ 上一篇/下一篇。
5. **分类 / 标签 / 归档 / 搜索**页面：同样卡片式。
6. **暗色/亮色切换**：右上角或侧边栏提供切换按钮，通过 `data-scheme="dark"` 或 Tailwind `dark:` 实现。

## 响应式

- 移动优先，断点参考：`sm 640px / md 768px / lg 1024px / xl 1280px`。
- 移动端：侧边栏折叠为顶部菜单，卡片单列。
